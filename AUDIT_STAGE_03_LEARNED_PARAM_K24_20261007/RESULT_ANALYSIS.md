## 3. 门禁验证结果（Promotion Gate Evaluation）

依据 `MASTER_PLAN.md` 预注册的 Promotion Gate 准则：
1. **Change 组指标**:
   - 准则：`change minADE 或 minFDE 至少一项 >= 3% improvement`，或 `change / clear-event coverage >= +1 pp`；
   - 实际：`change minADE = -1.88%`，`change minFDE = -1.58%`，`change coverage = -2.37 pp`；
   - **结论：未达成 (FAILED)**。
2. **总体损害限制**:
   - 准则：`overall minADE/minFDE 不允许 > 1% harm`；
   - 实际：overall minADE 改善 +0.92%，minFDE 改善 +1.67%，无损害；
   - **结论：达成 (PASSED)**。
3. **Seed 一致性**:
   - 准则：`2/3 seeds 同向正向通过`；
   - 实际：3 个 seed 在 change 组全部出现负向偏移（0/3 通过）；
   - **结论：未达成 (FAILED)**。
4. **运动学守护**:
   - 准则：`speed p95、accel p95 等相对变化在合理范围`；
   - 实际：speed p95 出现 +2.21%~+2.56% 的小幅上漂（略超 2% 界限）；
   - **结论：未达成 (FAILED)**。

综合判定：**PROMOTION GATE FAILED (Passing Seeds: 0 / 3)**。

## 4. 科学发现与深入反思（Scientific Mechanisms）

### 4.1 核心机制发现：确定性参数回归的“均值平滑陷阱”
1. **总体覆盖率虽然提升了 +1.00 pp**：
   在总体 1,561 个测试样本上，LearnedParam-K24 展现出了可重复的正向收益（平均净救回 15.7 个窗口，J 下降 0.65%，minADE 改善 0.92%）。
2. **收益的全部来源是普通步态，而非极端突变**：
   细分群组清晰地揭示了收益的结构：
   - 平稳组覆盖率从 74.57% 提升至 76.20%（净 +16 个窗口）；
   - 平缓过渡组覆盖率从 65.77% 提升至 67.39%（净 +6 个窗口）；
   - **然而在 211 个真实的动作突变窗口（Change）中，覆盖率反而下降了 -2.37 pp（净丢失 5 个窗口），minADE 恶化了 1.88%！**
3. **解释（Mechanism）**：
   静态基准（Static-K24）采用的是强烈的先验假设（例如：急转弯赋予严格的 $\pm 75^\circ$，骤停赋予强烈的减速比例）。这些先验虽然生硬，但在发生极端事件时构成了极高价值的“探索极点”。
   当引入由过去观测训练的确定性神经网络回归时，模型在遇到模糊过去线索时不可避免地向训练集的中间速度和角度靠拢（Regression to the Mean）。这虽然让大量正常直行和微幅微调的样本拟合得更准，却把急转弯和紧急骤停的提议“平滑化”了，导致极端突变难例的探索覆盖反而丢失。

## 5. 严格科学结论（Four-Tier Framework）

- **OBSERVATION（数据事实）**:
  LearnedParam-K24 在总体上实现了 3-seed 平均 +1.00 pp 的覆盖率提升（67.97% $\rightarrow$ 68.97%）和 +0.92% 的 minADE 改善；但在 Change 突变难例上，覆盖率下降 2.37 pp，minADE 恶化 1.88%，未能达到预注册的 Promotion Gate。
- **INTERPRETATION（因果解释）**:
  基于过去表征的确定性连续参数回归能够优化日常行走的微观步态动力学，但在缺乏未来多模态感知的前提下，确定性回归会抹平离散先验的极端探索能力，无法有效解决突变意图的召回。
- **NOT PROVEN（未证明事项）**:
  未证明过去表征具备预测剧烈突变动力学参数的能力。
- **DECISION（状态机决策）**:
  根据预注册状态机规则（`scripts/decision_engine.py`），Promotion Gate 未能通过。
  触发安全停机：**`STOP_LEARNED_PARAM_NO_GAIN`**。
  长运行实验至此按照预注册规范严谨终结，不随意修改门禁阈值，不随意调参，如实记录阴性证据（`SUCCESS_SCIENTIFIC_NEGATIVE`）。

# RESULT_ANALYSIS: Motion Program Target Identifiability Audit

## 1. 实验目标与研究背景
在 Stage 03 中，确定性单点参数预测在 Stable/Transition 组获得了 +1.6 pp 覆盖率提升，但在 Change 突变难例上出现 -2.37 pp 的平滑退化。
本诊断实验旨在彻底区分两种互斥的底层机制：
- **假设 A (参数标签简并/不可辨识)**:
  8 维连续参数由于内部物理耦合（如 onset 与 $\theta$ 补偿、速度与 persistence 补偿）存在多解，导致单点点回归属于 ill-posed 目标；
- **假设 B (历史条件未来本质多模态)**:
  参数本身具有良好物理唯一性，但相似历史观测条件下，行人真实的未来运动程序天然存在多种完全不同的分叉分支（如左转、直行、骤停）。

---

## 2. 实验 A 结果：Oracle 参数唯一性检验 (16 Restarts)

对 Zara Outer 全部 211 个 Change 难例及 211 个 Stable 样本，进行 16 次独立随机初始化的 GPU 优化，提取近最优解集合（$Q \le 1.01 Q_{\text{best}}$）：

| 评估指标 | Change 难例组 ($N=211$) | Stable 平稳组 ($N=211$) | 简并性判定阈值 |
|---|:---:|:---:|:---:|
| **平均近最优解数** | 9.6 / 16 | 2.9 / 16 | — |
| **轨迹空间离散度 $D_\tau$ (Pairwise ADE)** | **0.0055 m** (中位数 0.0018 m) | **0.0025 m** (中位数 0.0000 m) | — |
| **归一化参数空间离散度 $D_z$** | **0.0537** (中位数 0.0244) | **0.0276** (中位数 0.0000) | — |
| **参数简并样本比例 ($D_\tau \le 0.05\text{ m} \land D_z \ge 0.15$)** | **3.79% (8 / 211)** | **3.79% (8 / 211)** | $\ge 30\%$ 门禁 |
| **转角标准差 ($\theta_1, \theta_2, \theta_3$)** | $0.7^\circ, 1.1^\circ, 1.4^\circ$ | $0.1^\circ, 0.1^\circ, 0.1^\circ$ | — |
| **速度比标准差 ($s_1, s_2, s_3$)** | $0.014, 0.012, 0.016$ | $0.003, 0.004, 0.004$ | — |
| **Onset 标准差 / Persistence 标准差** | 0.14 步 / 0.09 | 0.09 步 / 0.05 | — |
| **Onset-$\theta$ 交叉补偿相关性** | $+0.040$ (极弱) | $-0.007$ (无相关) | — |

### 实验 A 结论:
**彻底否定“参数标签简并/不可辨识”假设！**
在 96.21% 的样本上，16 次随机重启收敛到的参数在物理空间高度集中（转角漂移仅 $\sim 1^\circ$，速度漂移仅 $\sim 0.01$），简并率仅 3.79%（远低于 30% 阈值）。
给定未来真实轨迹和指定机动类型，8 维运动程序参数 $z$ 是一个具有极高唯一性与可辨识度的物理量。

## 3. 实验 B 结果：历史条件未来多模态检验 ($k\text{NN}=20$)

利用表现最好的 P2 终层时空编码（96 维），在合法训练集（$N=16,337$）中检索 211 个 Change 难例的 $k=20$ 个历史最近邻：

| 评估指标 | 实测数值 | 判定基准 / 理论极值 |
|---|:---:|:---:|
| **Top-20 历史近邻平均余弦相似度** | **0.8847** | 证实过去时空状态高度相似 |
| **Top-20 邻居涵盖的独立机动类别数** | **4.00 类** (最大 7 类) | 若单模态应为 $\approx 1$ 类 |
| **机动类别分布信息熵** | **1.471 bits** | 理论最大熵 $\sim 2.81$ bits |
| **$\ge 3$ 个不同机动类别的样本占比** | **77.73% (164 / 211)** | $\ge 40\%$ 门禁 |
| **邻居未来转角 $\theta_3$ 标准差** | **28.1°** | — |
| **邻居未来转角 $\theta_3$ 跨度极差 (Max - Min)** | **111.1°** | 呈现巨大的角向扇面分散 |
| **具备显著角向双峰/多峰分叉的样本比例** | **77.25% (163 / 211)** | $\ge 35\%$ 门禁 |
| **终末速度比 $s_3$ 标准差 / 跨度** | **0.523 / 1.471** | 兼具骤停 ($0.1$) 与加速 ($1.4$) 分叉 |

### 实验 B 结论:
**强烈证实“历史条件未来本质多模态”假设！**
在超过 **77%** 的 Change 难例中，即便过去观测极为相近（余弦相似度 0.885），行人的真实未来运动程序依然发散为平均 4 种截然不同的机动模式，且转角跨度高达 $111^\circ$。

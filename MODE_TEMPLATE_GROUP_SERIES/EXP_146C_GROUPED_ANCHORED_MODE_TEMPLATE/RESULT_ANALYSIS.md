# EXP-146C 结果分析

146C 是本轮数值最全面的版本：

- General minADE 相对基线改善约 1.11%，Top-1 ADE/FDE 改善约 0.57%/0.37%；
- Challenge minADE/minFDE 改善约 0.85%/0.17%，Top-1 ADE/FDE 改善约 0.19%/0.11%；
- minFDE 在六组配对中均下降，但绝对幅度很小。

其主要收益仍来自锚点模板。五组成员数为 `[1, 2, 5, 2, 10]`，实际推理只使用第 1、4 组，Challenge 几乎退化为固定选择第 1 组。精确最佳候选命中率没有提高。

结论：可作为小幅增量参考，但不应成为新的核心模型；不建议继续围绕当前固定分组搜索超参数。完整对比见上级目录 `RESULT_ANALYSIS.md`。

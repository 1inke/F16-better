# ETH/UCY Oracle Interaction Series 最终报告

## 实验目标与控制变量

本轮目标不是改善候选评分，而是通过前端交互编码提高 K=20 候选集合的 Oracle 上限。所有有效实验固定：

- `KinematicAnchorDecoder, K=20`，decoder fingerprint `49e563b0bba12533`；
- `ModeQueryLoss` 与 classification weight 0.5；
- ETH/UCY Univ 完整场景留一验证；
- 观察 8 帧、预测 12 帧；
- F16 temporal-social cross attention 为基线。

首次批处理误用旧 Q20 的结果已经单独移动至各实验的 `results_invalid_q20_20260822`，不参与结论。

## 关键诊断

### 1. 简单扩大交互范围不是当前答案

ETH/UCY 当前输入最多 9 个智能体，数据预处理本身已经形成局部邻域。额外加入 3–12 m 远场边显著降低 Oracle，说明扩大范围在此口径下主要增加无关关系。该方向更适合未来 SDD 可变人数输入，而不是当前 ETH/UCY。

### 2. 显式关系偏置能影响终点，但不足以稳定改善整条轨迹

F43/F45 都曾在单种子上改善 minFDE，但三种子下 minADE 与 same-path FDE没有同步改善。这说明冲突关系能够推动某些候选终点，却没有稳定改善候选轨迹的中间形状。

### 3. 二阶均值摘要会抹平个体意图

F44 的 same-path FDE有所改善，但 minADE/minFDE退化且参数增加 3.42%。群体均值并不是合适的高阶表示；如果未来重做，需要方向分组或可学习少量 group tokens，不能继续使用无差别均值。

### 4. 当前 Oracle 瓶颈更接近候选几何表达能力

固定 K20 解码器以恒速外推为中心，使用固定 heading-aligned endpoint anchors，并用 4 个正弦基函数生成中间残差。编码器最终只能通过平均池化后的上下文调节这些固定锚点与有限残差。注意力改造能改变上下文，但无法改变候选基底的覆盖形状，因此 minADE 长期停留在约 0.16 附近。

这不是候选“评分”问题，而是候选“生成基底/覆盖”问题。若目标是继续显著降低 minADE/minFDE，下一步应保持 K=20 和轻量运动学框架，但允许编码信息控制候选几何，例如：

1. 数据驱动但受运动学约束的条件锚点尺度/旋转；
2. 终点之外增加一个稀疏中间控制点，以覆盖转弯时刻；
3. 将固定正弦残差换成少量可学习、仍可解释的运动基底；
4. 训练时增加候选覆盖损失，仍暂不改 Top-1 评分器。

## 当前决策

- 默认模型继续保留 F16 + kinematic K20。
- F42/F43/F44/F45 均不替换基线。
- ETH/UCY 上不再优先投入“扩大邻域/增加关系偏置”的注意力实验。
- 下一系列应专门优化 Oracle 候选几何与覆盖，同时锁定评分逻辑，避免和候选选择问题混淆。

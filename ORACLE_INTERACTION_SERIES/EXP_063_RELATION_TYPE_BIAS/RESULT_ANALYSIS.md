值得复验。仅增加 192 参数（约 0.067%），minADE 基本持平，same-path FDE 改善约 2.38%，minFDE20 改善约 2.30%。由于首轮 F43 使用 monotonic cosine，而历史 F16 使用 warm restarts，必须在相同调度器下做 seeds 1/2/3 后再判断。

最终不通过。F43 的平均 minFDE 改善约 0.67%，但 minADE 退化约 2.24%，same-path FDE 退化约 0.88%，且不同种子方向不一致。六类关系自由度没有形成稳定收益，后续收缩为单一运动学冲突偏置实验。

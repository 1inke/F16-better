# 候选生成—模型筛选人工复核

双击 index.html，无服务器、网络或GPU依赖。全部1516个既有ETH开发案例，不是独立测试。来源是已审计的原生F16 V2 seed1：20条final候选与原模型真实logits/argmax。不是最新生成修正实验，也没有用旧分数假称重新评分。

默认分类：同一条候选ADE<=0.30m且FDE<=0.50m才算接近；joint=A​​DE+0.5FDE仅用于本诊断选择损失排序，不冒充生产训练目标。joint regret<=0.20m为选择接近最优。阈值可改，分类立即重算，可导出当前分类CSV。是描述性阈值，无外部公认标准、无DEV调参/修改正式门槛。

八个互斥分类，依次判断：准确选中双oracle、准确选中可接受非双oracle、好候选未选中、ADE/FDE分属不同候选、仅路径接近、仅终点接近、候选不足选择接近最优、候选不足且选择额外损失。oracle是事后使用GT的评估参照，不是推理输出；exact oracle命中率不等于预测质量。

界面显示相对最后观测位置的物理坐标(米)，等比例坐标，8步历史/12步未来dt0.4s。20条候选全部绘制；可比较粗轨迹与refiner后最终轨迹，模型选中、GT、ADE/FDE/joint oracle独立高亮；表格点击可看任意候选，时间滑块查看逐时刻。softmax只是原生评分的归一化，不是经校准的真实概率。速度/加速度/jerk为有限差分描述，不凭单案例推断机制或安全性。

分类CSV保留所有样本，不只挑好看的图。排序最大regret用于定位失败，默认样本ID顺序用于避免只看极端案例。可导出人工标注JSON，与固定样本ID对应：支持人类形成假设，不作为独立泛化证明、不训练任何模型。没有图像场景/地图/邻居背景，不据图判定碰撞或场景可行性。

输入只读，audit.json保存输入SHA前后和全部数值核验。没有旧结果/模型/科学脚本改写。人工评审后若选新实验方向应预注册并继续原有对照/审计标准。

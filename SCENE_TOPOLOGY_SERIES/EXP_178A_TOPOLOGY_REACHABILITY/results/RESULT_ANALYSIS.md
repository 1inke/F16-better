# EXP-178A Topological Scene Reachability Audit 结果分析

## 结论

**EXP-178A 明确 FAIL，停止 scene-topology training，不进入 EXP-178B。**

本实验完整覆盖标准 SDD 测试集 17 个视频、2,679 个样本。轨迹模型保持为冻结的
`F16 + H3 + Joint-V2 + original score + K20`。离线 walkability CNN 只有 9,729
个参数，并且只使用训练视频轨迹弱监督；验证/测试轨迹没有参与拓扑资产和 proposal
构建，测试 future 只用于冻结后的 Oracle 评估。

## 总体结果

| 指标 | Baseline K20 | K20 + topology | 相对提升 | PASS 要求 |
|---|---:|---:|---:|---:|
| minADE | 7.5768 px | 7.5631 px | 0.18% | 任一 Oracle 指标 >= 5% |
| minFDE | 12.3872 px | 12.2263 px | 1.30% | 任一 Oracle 指标 >= 5% |
| same-path FDE | 14.4888 px | 14.4291 px | 0.41% | 辅助报告 |

- 正向测试视频：7/17，要求至少 12/17。
- little 子集：minADE 0.00%，minFDE 0.67%，要求至少一项达到 8%。
- 三项主门槛全部失败。

## 新候选实际命中范围

拓扑分支平均为每个样本生成 2.50 条 proposal，但有效增益非常稀疏：

| 指标 | 新候选获胜样本 | 获胜比例 | 命中时平均收益 |
|---|---:|---:|---:|
| minADE | 8/2679 | 0.30% | 4.60 px |
| minFDE | 40/2679 | 1.49% | 10.77 px |
| same-path FDE | 6/2679 | 0.22% | 27.48 px |

这说明拓扑 proposal 偶尔能覆盖 K20 没有覆盖的尾部终点，但它不是稳定、广泛存在的
候选缺口。少数命中时收益较大，无法弥补超过 98% 样本不产生增益的问题。

## 拓扑信息是否能判断候选质量

候选内部 Spearman（feature 与负质量误差）为：

| 特征 | Overall | Little | 判断 |
|---|---:|---:|---|
| 历史方向一致性 | 0.453 | 0.421 | 强，但属于运动学信息 |
| 拓扑综合一致性 | 0.054 | -0.024 | 很弱，little 上反向 |
| 平均 walkability | 0.044 | -0.070 | 很弱且跨域不稳定 |
| path connectivity | 0.031 | -0.077 | 很弱且跨域不稳定 |
| reachable endpoint | 0.018 | -0.083 | 很弱且跨域不稳定 |
| endpoint skeleton distance | -0.014 | 0.063 | 近零、方向不稳定 |

唯一清晰的相关信号是“候选是否沿历史运动方向”，而该信息已经属于现有运动学编码，
并不能证明参考图拓扑提供了新的未来方向信息。场景特征本身未形成可迁移的候选质量信号。

## 失败原因

1. 弱监督拓扑可以形成视觉上的可通行骨架，但无法从静态参考图判断行人在多分支中的真实意图。
2. 生成器沿骨架给出几何可达路径，却缺乏目的地和行为条件，因此大多数 proposal 合理但不相关。
3. 收益主要体现在极少数 FDE 尾部命中，ADE 和 same-path 改善更少，说明中间路径与真实运动细节仍不匹配。
4. little 子集没有得到预期收益，证明该方法没有解决当前 SDD 最明显的困难域。

## 决策

- 不运行 EXP-178B Topology-Conditioned Proposal。
- 不为该分支补 seeds 2/3，也不扫描阈值、分支数或 topology loss。
- 保留 EXP-178A 作为“静态场景拓扑不能稳定补充 K20 候选”的负结果。
- 按指导转向 EXP-179A Candidate Perturbation-Stability Audit，检验模型自身的不确定性
  是否能提供独立于原评分的可靠信号。

极少数尾部命中可以作为未来的诊断证据，但只有在获得可靠的 tail-need 触发器后才值得重新
考虑；当前结果不足以支持训练或接入场景拓扑分支。

# EXP-172 官方五折编码器消融结果分析

## 结论

本轮 20/20 个组合均已完成。固定相同的折内官方 H3+V2 解码器后，**E2（关系先验 / `f4_relation_tokens`）在 seed 1 上取得最优五折宏平均**；E3（F16 时序—社会交叉）相对 E2 的 J 差值仅为 0.004079（相对约 0.99%）。这一差距尚未经过 seeds 2/3 与 SDD 验证，不能据此宣告 E2 稳定优于 F16或淘汰F16。现阶段应同时保留 E2 与 F16 两个候选。

## 五折宏平均（seed 1）

|---|---:|---:|---:|---:|---:|---:|
| E0 纯轨迹基线 | 0.237732 | 0.391787 | 0.462481 | 0.433626 | 0.540513 / 1.099674 | 215,082 |
| E1 稀疏因子化交互 | 0.230536 | 0.378810 | 0.450232 | 0.419941 | 0.529368 / 1.085856 | 321,988 |

提升率统一采用 `(旧误差-新误差)/旧误差`，数值越低越好。

## 增量归因

- E0→E1：minADE 降低 3.03%，minFDE 降低 3.31%，J 降低 3.16%。因子化稀疏交互是明确有效的第一层增益。
- E1→E2：在参数量不变的情况下，minADE 再降低 1.96%，minFDE 再降低 2.26%，J 再降低 2.09%。关系 token/关系先验提供了独立且具有较好性价比的增益。
- E0→E2：minADE 降低 4.93%，minFDE 降低 5.50%，same-path FDE 降低 4.22%，J 降低 5.19%；top-1 ADE/FDE 同时降低 4.79%/3.75%。这说明改进不只扩大 oracle 候选覆盖，也改善了模型实际评分后的首选轨迹。
- E2→E3：minADE 上升 1.20%，minFDE 上升 0.74%，J 上升 0.99%。额外的多尺度关系与时序—社会交叉融合没有形成互补，当前训练口径下属于负增益。

注意：E0→E1 不是“只打开一个图模块”的最小单变量消融；它同时从旧基线切换到 robust state + factorized interaction。因而可以把这一级解释为“稀疏因子化前端整体有效”，但不能把全部 3.16% J 提升都归因于稀疏注意力本身。E1→E2 的归因更干净，因为参数量相同、主要差异是关系信息的引入。

## 场景分析

E0→E2 的 J 误差下降率为：

| 场景 | J 下降 | 判断 |
|---|---:|---|
| ETH | 10.28% | 主要增益来源，交互/关系先验在复杂运动场景中最有效 |
| Hotel | 2.64% | oracle 提升一般，但 top-1 ADE/FDE 提升 12.77%/11.32%，排序和表征明显改善 |
| Univ | -0.07% | 基本持平，minFDE 与 same-path FDE轻微恶化 |
| Zara1 | 4.56% | 稳定正增益 |
| Zara2 | 1.82% | 小幅正增益 |

E2 在五折中的 J 表现为 4 胜 1 基本持平，并非单纯由某一折偶然翻转；不过宏平均的 5.19% 改善明显受 ETH 的大幅提升驱动。按测试样本数加权时，E2 仍然最优（J=0.407973），但相对 E0（0.410911）只降低约 0.72%。论文主表应继续采用 ETH/UCY 通行的五折等权宏平均，样本加权结果只作为泛化诊断，不能用来替换官方口径。

E3 相对 E2：Hotel 和 Zara2 有小幅正增益，但 ETH 明显回退，Univ/Zara1 也没有改善。这说明完整时序—社会交叉结构更可能存在场景依赖或优化干扰，而不是稳定的普适提升。

## 参数与效率判断

- E2 相对 E0 增加 106,906 个总参数，增幅 49.70%；可训练参数由 159,677 增至 266,582，增幅 66.95%。
- E1、E2、E3 的参数量完全相同，因此 E2 对 E1/E3 的优势不依赖额外参数。
- 本轮各运行的墙钟时间受系统状态影响很大（例如 E3/ETH 异常偏长），不能据此形成正式延迟结论。效率、FLOPs 和 N-scaling 应使用统一推理基准单独测量。

## 专业判断与下一步

1. **同时保留 E2 与 F16。** 当前结果只构成 seed-1 的名义排序，不构成模型淘汰证据。
2. **按照原指导补齐四级消融的 seeds 2/3。** 官方编码器消融是论文证据，不是新方法筛选，因此 E0、E1、E2、F16 均应补齐，避免只复验表现较好的模型造成选择偏差。
3. 三种子汇总必须报告均值、标准差、逐折胜负以及 E2-F16 配对差；若置信区间或种子波动覆盖二者差值，应将二者记为统计上未分胜负。
4. 随后按指导完成统一 FLOPs、参数量、batch1/batch64 延迟、峰值显存、edge ratio、attention elements 和 N=4/8/16/32/64 scaling。效率比较至少保留 E0、简单/稠密交互、E2 与 F16。
5. SDD 外部有效性验证不属于本份 EXP-172 指导的当前步骤，应在 ETH/UCY 多种子和效率证据完成后单列协议；届时 E2 与 F16 都进入 SDD 对比。

## 口径限制

固定解码器来自各折原始 F16+V2 检查点，而各编码器在该冻结解码器下重新训练。这保证了解码器完全一致，但不是每个编码器各自联合训练后的性能上限。该设置可能对不同编码器产生不同的特征适配影响，因此当前结果只用于受控编码器消融；若后续需要比较 E2 与 F16 的最终模型上限，还应分别进行同协议的端到端联合训练，并在 SDD 上做外部有效性验证。

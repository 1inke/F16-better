# 下一系列指导：完整运动模式的责任学习与迁移

日期：2026-10-15（香港）；版本1.0；状态：**DESIGN ONLY，未实施、未预检、未启动**。

## 先读这个结论

本系列不续跑M2、不启动原M3，不继续调整终点投影、加速度系数、head宽度或训练轮数。换一个可检验的假设：

> 从FIT完整运动轨迹建立固定模式支撑后，让每个模式学习相对稳定的训练责任，能否比动态best-of-K winner带来更可迁移的完整候选覆盖？如果有收益，它是否真正依赖观测信息？

这是提出一个新方向，不是宣布固定责任必然优于WTA，也不是已经证明旧loss有问题。新方案仍可能失败于原型粗糙、罕见模式不足、共享参数干扰或泛化。它不以分类分数挑候选，不做native底部槽替换，不训练scorer；始终直接输出20条完整路径。

## 证据起点

来自[M2结果](../MOTION_STATE_GOAL_PROCESS_DESIGN_20261014/M2_execution_20261014/RESULT_ANALYSIS.md)与[复核](../MOTION_STATE_GOAL_PROCESS_DESIGN_20261014/M2_execution_20261014/completion_review/REVIEW.json)：

- outer change原生覆盖110；M2过程未训练P0为100/91/109；冻结目标训练A为93/91/110；联合训练B为101/90/101。
- B在FIT change覆盖2334/2345/2384，高于P0的2074/2099/2105，但没有稳定转到outer，原CAL也低于native。
- A/B全部96个seed×split×group运动学记录均有平均加速度失败；B减轻代价，不等于解决。
- 20个候选几乎都是不同簇，故不是简单的候选复制塌缩。M2-P0沿用已训练G1目标，并非全系统未经学习。

这些支持研究“学习增量及其迁移”，不能单独支持“固定assignment就是答案”。本新系列不将旧G1/G2/M2作为新架构的单因素对照。

## 三个明确改变

1. **从预测终点再补过程，改成完整运动模式加条件修正。** 不使用M2的S650端点投影。原型只给初始化支撑，不锁定最终终点，也不保证物理安全。
2. **把责任分配作为一个独立因素。** 同一新架构、同一初始化，比较动态Q-winner和固定FIT模式责任；不同时增加平滑惩罚、分类器、保护项。
3. **把“训练增量”与“观测信息价值”分开验证。** 每次都保存初始化；有学习收益后，再单独比较是否提供P2观测表示，最后才做迁移。

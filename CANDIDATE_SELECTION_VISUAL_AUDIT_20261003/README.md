# 候选 → 评分 → 选择：人工可视化诊断

直接打开 `index.html`，无需安装或联网。所有1516个样本、每样本20条候选均可浏览；分类、排序、阈值敏感性和人工备注均在本地工作。`gallery.html` 是按明确规则抽取的分类代表案例入口。

## 数据与模型身份

主视图是**当前生成研究使用的不可变原生F16/V2基线**：ETH、generator seed1、既有development1516显式ID、8帧观察/12帧预测、dt=0.4秒。使用原生logits的argmax，是真实模型选中轨迹，不使用GT选择。

另提供最近完成的PAIRWISE_HISTORY / NEIGHBOR_READOUT / NEIGHBOR_MESSAGE的constrained seed1候选比较。它们只研究生成修正，没有重新评分校正后的轨迹；其中的选择线必须称为**继承原生slot选择参考**，不是新模型重新打分、部署效果或当前最佳方案。seed1是预先固定展示种子，并非按效果挑选。正在运行的cycle11不读取、不打断。

不混用旧EXP-173 rankability可视化缓存：它与当前fold-local基线虽然ID一致，候选和评分数值不同。来源SHA及误差验证见`audit.json`。GT从已有ETH train原数组按锁定dev ID恢复，仅用于事后比较，没有官方test访问。

## 六类诊断（互斥且覆盖所有样本）

默认“接近”仅为可修改的诊断口径：ADE≤0.30m且FDE≤0.50m，**必须同一候选同时满足**。这不是实验通过门槛。

1. **选中合格轨迹**：实际选择同时满足两阈值。不要求精确等于minADE/minFDE；精确最优命中另列。
2. **合格候选被漏选**：集合有同时达标候选，实际选择不同时达标。说明给定集合/口径下有选择改进空间，不证明信息可学或排序是唯一主因。
3. **分离最优的指标错觉**：minADE和minFDE分别达标，但没有同一条候选双达标。单看两个min指标会误以为已有好轨迹。
4. **仅路径接近**：minADE达标，minFDE不达标。
5. **仅终点接近**：minFDE达标，minADE不达标。
6. **整体覆盖不足**：两个min指标均未达标。仅描述对已发生GT的覆盖，不等于未来不可预测或模型容量不足。

连续指标保留：selected/min ADE/FDE、ADE/FDE regret、单轨迹联合误差Q=ADE+0.5FDE与regret、minADE/minFDE是否同slot、两最优轨迹的交叉误差、合格候选数、最优候选在原生评分中的排名、重复率/终点分散度、所选轨迹速度/加速度/jerk。精确argmin以最小slot破平局；另用1e-6m容差标注质量并列最优。

## 浏览方式

- 左图：全部候选、GT、观察历史；点击候选或表格，联动高亮。
- 中图：候选ADE–FDE质量平面，阈值框只表示同路径双达标；模型分数见右下排序表。
- 右图：模型选择与GT，叠加minADE、minFDE或联合最优作为事后参照。
- 三图时间与候选slot一致；两空间图同样范围且1:1米制比例。默认不裁掉远候选。
- 分类、运动组、最优命中、样本ID、regret排序用于逐例查找。运动组来自GT事后标签，不供推理。
- 点击“保存本例备注”才会写入浏览器localStorage；未保存草稿在本页面切换图层/样本时保留，重载或关闭页面不保证保留。可导出JSON；不会回写旧模型或实验结果。切换浏览器/文件位置可能不共享备注。
- 若内嵌浏览器不支持下载，导出按钮仍会在“导出文本备份”显示同一份JSON或SVG，可选中复制并保存为提示的文件名。不要只依赖浏览器本地存储长期保留研究备注。
- 阈值可调整，列表与统计即时重算；CSV默认口径不被改写。三档敏感性另保存。

`REPORT.md` 是全量统计与解释，`per_sample_classification.csv` 为4组×1516行精确数据，`candidate_metrics.csv.gz` 为全部候选逐条数据。`data/arrays.npz` 保留精确坐标；网页坐标仅显示时舍入5位小数。源文件不改、无训练、无新实验计数。复现：`python -B build_audit.py`；重跑已有输出需显式`--rebuild`，仅允许本目录派生产物。

不能仅凭视觉或阈值类别做因果归因；单GT不能否定其他合理未来，softmax评分不是校准概率。这里的目标是帮助人类提出可验证的新假设，而不是自动决定实验成功。

## 验证与示例

`test_classification.py` 含六类边界/同路径/并列最优/不使用GT选择的纯数据测试；`test_web_data.js` 验证4组全部6064分类行、288阈值分组计数、全部2910720网页坐标有限性与舍入误差。浏览器验证记录在`UI_QA.json`；桌面和390px窄屏布局均检查，两空间图相同大小且等比例，无横向页面溢出。网页实测使用localhost；直接文件打开的兼容性未作浏览器实测，不依赖fetch、第三方脚本或CDN。

建议从代表案例ID9019开始：它是“合格候选被漏选”类别按联合选择遗憾中位数确定的案例，不是手工挑选最极端错误。`preview_case.jpg`、`preview.jpg`和`example_ID9019_selection.svg`是可查看的输出示例。此例GT接近Slot12，原生评分却选Slot3；这能形成关于速度/方向判断的可检验问题，不能证明排序是全局主因。

# EXP-147：SDD 稀疏场景查询实验

## 实验目的

验证场景信息是否能在不改变稀疏社交注意力和运动学编码的前提下，直接改善候选轨迹覆盖。

本轮不是把整张图送入训练网络。SegFormer-B0 只在实验开始前对 60 张 SDD `reference.jpg` 离线运行一次，生成 160×160 的语义栅格。训练和推理阶段，每个候选只在 3 个锚点位置读取 6 维场景属性，再由一个小型 MLP 输出有界锚点修正。

## 严格对照

- `learned_anchor_control`：F16 编码器 + CV-free 三锚点候选生成；
- `semantic_anchor_query`：完全相同的底座，只增加锚点场景查询与修正；
- 两组使用同一 SDD 31/12/17 视频划分、同一随机种子、同一训练轮数；
- 为保持图像与轨迹坐标一致，两组都关闭反射和速度增强；
- 恒速外推不参与候选中心、参考点或损失。

## 输出

所有运行结果位于 `EXP_147A_SEMANTIC_ANCHOR_QUERY/results/`，汇总写入 `raw_result_summary.json`。原始数据、语义资产、模型权重和日志不会进入 GitHub。

## 快速筛选与复核

首次建议单种子 30 轮；只有当 S1 相对 S0 有明确增益时，再运行 1、2、3 三种子复核。预训练语义模型首次运行需要联网下载，后续会直接使用本地缓存。

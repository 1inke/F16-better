# 候选生成主线重审与快速分支测试

2026-10-14。结论：停止围绕 R1–R5 的可修复候选排序继续细调，把下一次学习实验重新指向完整 K20 候选生成。优先研究“去向/位移与条件化运动过程”，而不是继续扩大 selector 特征或直接改 scorer。

## 1. 为什么需要换回主问题

真正目标是：仅依据已观测历史和合法上下文，输出至少一条完整、高精度、物理合理的变化轨迹，并跨行人迁移。Hit@4、修复器可修复标签、训练 loss 都是中间指标，不能代替该目标。

证据不是“所有生成器均无效”：

- 方向3的必要可达界显示，旧 bottom4 + .20(t/12)^2 小修正，在 outer410个原生失败窗口中最多只能救6个；change143个失败最多3个。这个可行域本身不允许大突破。来源：[方向3原报告](../PED_FOUR_DIRECTION_SERIES_20261011/experiment3_samepath_quality/RESULT_ANALYSIS.md)。
- R3到R5主要测试可修复候选的排序。R5整体82→77/263，新增11个命中全来自原第5–8名，原深层106例没有一个进入前四；不应再把这类失败直接当作完整生成器无学习信号的证据。来源：[R5](../PED_REPAIRABLE_ANCHOR_SERIES_20261011/R5_TEMPORAL_MATCHING_DESIGN_20261013/production_20261013/RESULT_ANALYSIS.md)。
- 原五fold诊断中，UNIV的训练限定自身动力学探针残差SSE skill约+.116、加邻居约+.134，原top1为负；但ETH/HOTEL原模型更强。这支持“某些人口有未被充分利用的信号”，不是全数据不可预测，也不是邻居一定是唯一根因。该人口与本轮target outer不同，不能跨人口做纯因果归因。来源：[模型诊断](../PED_MOTION_UNDERSTANDING_SERIES_20261009/model_diagnosis_20261009/REPORT.md)。
- 旧kNN是32条残差的均值单路径，不是完整20候选生成器。因此未来候选生成比较应增加等K20经验运动库对照，不能拿这个单路径结果冒称已经验证了同预算生成基线。来源：[E6](../PED_MOTION_UNDERSTANDING_SERIES_20261009/stage3_knn_memory/RESULT_ANALYSIS.md)。

## 2. 本轮已经执行的快速测试

一次CPU保存输出结构诊断，41.760秒，无训练、无神经前向、无旧任务操作。完整使用 outer1035、inner1856、CAL2879，共5770个已保存窗口；不复用三seed相同native输入作为三份独立证据。协议先于新结果保存于 [DESIGN.md](DESIGN.md)。

四个端口：原生20；用真实终点为每条原生路径增加线性位移补偿；仅用真实终点构造一条匀速直线；用真实第4/8/12步关键点重构一条分段路径。后三者均使用GT未来，是诊断，不是可部署预测、不是新模型成绩。

### 这些数字支持什么

1. **去向/整体位移值得成为第一大分支。** 原生路径去掉终点偏差后，大量窗口能够跨过完整质量门；当前候选中并非完全没有可用时间形状。但这个操作同时改变全程位置和速度，不能称为精确的因果误差占比，也不保证学习器能预测真实终点。
2. **只会朝正确终点匀速走仍不够。** 尤其CAL变化组，真实终点直线只有258/700，而同终点原生形状有580/700。两者K分别为1和20，多样性与形状贡献没有被完全分离，不能把全部差异只归因于单条路径曲率。
3. **低维关键点足以近似本批已知真实路径，不等于关键点可预测。** 旧H3本身已有三锚点；本结果不是“再加三个节点”的新方法证据。需要解决的是从历史条件预测正确去向和过程，而非仅增加解码节点数。

### 物理反例不能省略

- 线性终点补偿保持离散加速度/jerk（验证最大差2.22e-14），三个变化组都通过原五项pooled门。
- 它仍在outer/inner整体及stable、CAL stable触发speed p95门，共5/12组失败；不是全组安全成功。
- GT三关键点重构在三个change组都未通过全五项门：outer/inner五项均失败，CAL四项加速度/jerk失败。分段位置插值不能直接作为最终物理过程设计。
- 原生1%相对运动学限制是现有工程门，不是“真实行人运动”的定义。GT自身值已保存作描述性参照，本次不修改任何旧门槛，也不据此升级baseline。

## 3. 大分支排序

| 分支 | 当前建议 | 一次快速、有决断力的测试 |
|---|---|---|
| 去向/位移 + 条件化时间过程生成 | 第一优先 | 新生成器直接输出K20完整路径；比较同条件输入下目标直线与目标+过程，不经过可修复selector或bottom4小修正 |
| 观测动力学表示 | 第二，和第一配合分开比较 | 固定同一生成解码器，原mean-token上下文 vs 保留时间顺序的raw位置/速度/速度变化编码；评价生成覆盖，不再评价P/N排序 |
| 交互条件生成 | 条件优先 | 自身运动版 vs 相对位置/相对速度/closest-approach版；只有生成收益和方向性干预响应相符，才认为交互支路有价值 |
| 候选整合与scorer | 暂后置 | 先让新候选自身有稳定覆盖和安全收益。原生support不随意删除；K24仅探索参考，不能当K20公平收益 |

已有速度basis、自由增量、Bernstein、物理投影、median-MoE等失败仍需作为反例保留。不能仅把旧局部head换名为“运动程序”。新主线的实质区别是取消强制bottom4局部可行域，直接预测完整多模态未来，并检验观测条件是否对这些预测有真实作用。

## 4. 下一次短学习测试：明确边界，不开长期工程

此节是下一步方案，**本轮未运行学习模型**。

使用现有target-disjoint 18909训练、1035 outer、1856 inner与2879原CAL；无新数据，无原F16/decoder/scorer权重修改，旧长E3保持暂停。

### 第一轮：目标与过程，最多一次短筛选

- 两个fresh轻量生成基线，共同使用原P2上下文和明确顺序的过去8步位置/7步速度，不输入原生未来、GT、group、slot排序。
- A：预测20个未来终点，以固定直线时间插值形成20条完整路径。
- B：预测20个终点及每个终点条件下的两个中间控制点/连续速度过程，生成20条完整路径。终点和过程在预测时全部来自历史；训练GT只用于损失。
- K20、样本顺序、25epoch、3seed42/43/44、原canonical完整路径winner与diversity定义固定；这是表示族的快速比较，参数/有效容量差异明确报告，不能宣称纯因果的单因素证明。
- 不引入新的可修复标签，不预先筛选容易生成的窗口，不扫节点/宽度/系数。原native20只做外部冻结基线，不要求每条新路径都围绕旧候选.2m。
- 先实现与小样本核验；根据真实吞吐决定是否能在30分钟生产预算内完成。超预算不自动扩张或偷偷减epoch；实现/预检时间与生产时间分开报告。尚无本方案实测ETA。

若B不能稳定优于A和原生候选，停止这版，不再做B内部的细碎微调。若B有清晰效果，再做第二轮原P2压缩表示 vs 顺序动力学编码；最后才加交互分支。

### 决策标准

- 首先同路径完整覆盖、rescue−lost、变化组ADE/FDE、J；同时列stable/transition保护。
- 全五项motion门不放宽。覆盖改善但运动学失败只能标记“质量—物理权衡”，不是突破。
- 三seed方向、paired track区间、跨split反例；single seed快速正例不升级baseline。
- 增加固定等K20训练经验轨迹库/恒速参考，避免将“撒更多路径”当作理解。
- 用末两点保留的历史交换或前段打乱作诊断：正确历史是否比错误配对历史更有帮助；这是分布外敏感性检查，不是单独的运动理解证明。
- 后续理解主张还需要跨行人迁移以及邻居改变时方向合理的响应；高oracle覆盖只是必要证据之一。

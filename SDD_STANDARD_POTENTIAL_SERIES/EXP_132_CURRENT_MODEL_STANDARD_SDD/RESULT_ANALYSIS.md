# EXP-132：当前模型在整体 SDD 上的结果分析

## 1. 结论

当前模型在 SDD 上具有明确的继续研究价值，但还不能称为整体竞争力充分。

- `minADE20 = 9.237 px`：已经进入 PECNet、Trajectron++、MID 所在区间，并优于三者公开表格值。
- `minFDE20 = 17.993 px`：明显弱于公开基线，说明候选能够贴近未来路径，但终点覆盖不足。
- 模型仅有 `284,642` 个参数，且没有场景图像分支；在这一前提下取得 9.24 px 的 minADE20，证明当前轨迹编码、运动学稀疏交互和轻量候选生成能够迁移到 SDD。
- 主要退化集中在 `little` 场景，而不是所有测试视频普遍失败。

因此，准确表述应为：**当前模型已经表现出较强的路径预测潜力，但跨场景尺度适配和远期终点覆盖仍是 SDD 上的短板。**

## 2. 整体指标

| 指标 | 验证集 | 测试集 | 测试相对验证变化 |
|---|---:|---:|---:|
| minADE20 | 6.921 px | 9.237 px | +33.5% |
| minFDE20 | 12.935 px | 17.993 px | +39.1% |
| best-ADE 同路径 FDE | 14.968 px | 20.315 px | +35.7% |
| Top-1 ADE | 14.516 px | 17.697 px | +21.9% |
| Top-1 FDE | 28.061 px | 34.352 px | +22.4% |

最佳 Oracle checkpoint 出现在第26轮；第30轮只发生轻微回落，训练过程正常，没有后期崩溃。完整30轮耗时 `723.4 s`，约12.1分钟。

## 3. 与公开结果的近似比较

| 方法 | minADE20 / minFDE20（px） | 当前模型相对关系 |
|---|---:|---|
| 当前模型 | **9.24 / 17.99** | — |
| Trajectron++ | 9.90 / 16.80 | ADE好6.7%，FDE差7.1% |
| PECNet | 9.96 / 15.88 | ADE好7.3%，FDE差13.3% |
| MID | 9.73 / 15.32 | ADE好5.1%，FDE差17.4% |
| MemoNet | 8.56 / 12.70 | ADE差7.9%，FDE差41.7% |
| GSMNet | 8.30 / 12.70 | ADE差11.3%，FDE差41.7% |

当前实验重新从原始标注生成了2679条测试轨迹，而公开 PECNet 文件包含2829条，邻居打包方式也属于当前模型专用实现。因此该表适合判断量级与潜力，不应直接作为论文中的严格 SOTA 排名。

## 4. 相对恒速基线

测试集恒速外推结果为 `19.104 / 38.200 px`。

- 当前 Top-1 为 `17.697 / 34.352 px`，ADE/FDE 分别改善约7.4%和10.1%。
- 当前 Oracle 为 `9.237 / 17.993 px`，ADE/FDE 分别改善约51.7%和52.9%。

这证明模型不是仅依靠恒速先验得到当前结果。编码上下文与多候选生成产生了很大的有效增益；但已学评分器只能兑现其中一小部分。

去掉 `little` 四段视频后，剩余2161条测试轨迹为：

- `minADE20 = 7.914 px`
- `minFDE20 = 15.283 px`

再去掉只有14条样本的 `nexus/video5` 后为 `7.844 / 15.120 px`。这说明整体短板高度集中于特定域。

`little` 的观察期平均单步像素位移约14.6–18.0 px，而多个正常场景约7–12 px。当前统一的20 px坐标缩放、固定运动学锚点尺度和训练速度扰动不足以覆盖这种视频尺度变化。

## 6. 两个不同的瓶颈

### 6.1 Oracle终点覆盖

测试 `minADE20=9.237`，但 `minFDE20=17.993`，best-ADE候选的同路径FDE更达到20.315。候选在前中段可以接近真实轨迹，但远期端点的方向或幅值不足。

这一问题在高速、尺度不同的 `little` 场景最明显，优先指向：

1. 跨视频像素尺度没有规范化；
2. 固定候选锚点的速度/长度范围不足；
3. 训练集速度分布对完整留出的 `little` 场景覆盖不足；
4. 没有场景分支提供道路、入口和可通行区域约束。

### 6.2 Top-1候选排序

测试 Top-1 ADE/FDE 为17.697/34.352 px，约为 Oracle 的1.9倍；Top-1 命中 best-ADE 候选的比例只有19.6%。这延续了 ETH/UCY 实验中的评分问题。

不过公开 SDD 表格主要比较 best-of-20，因此当前判断模型候选能力时，应先看9.237/17.993，而不是把 Top-1 与公开 min20 混合比较。旧 ETH/UCY verifier 没有用于测试集，`fused=null` 是正确行为。

## 7. 后续判断

当前证据支持继续使用本模型作为 SDD 研究底座，理由是：

1. 仅约28.5万参数且没有场景图像，minADE20 已达到传统强基线区间；
2. 在大多数测试视频上结果明显优于总体均值；
3. 失败与视频尺度、高速运动和完整留出场景高度相关，属于可定位问题；
4. 稀疏注意力、运动学先验和轻量化结构没有表现出系统性失效。

但暂时不能宣称整体 SDD 有竞争优势，因为 minFDE20 仍弱，且当前协议是近似对齐。下一轮最有价值的不是盲目扩大模型，而是先做“尺度/速度适配”隔离实验：保持 F16、Top-K=4 和参数规模不变，对坐标尺度、速度分层增强及候选幅值进行少量对照。若能够主要修复 `little` 而不损伤其他场景，再考虑加入轻量场景分支。

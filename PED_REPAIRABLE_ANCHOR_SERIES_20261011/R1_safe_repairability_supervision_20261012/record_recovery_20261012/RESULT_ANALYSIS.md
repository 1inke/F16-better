# R1：安全可修复监督选锚对照——结果分析

分析日期：2026-10-12（香港时间）。状态：**执行和保存复核通过；科学推进门未通过。不进入 B 迁移或 S2。**

## 1. 核心结论

小幅 position3 修正并非在所有困难样本上都无解：这批384个事先筛选的机会窗口中，263个找到至少一条严格安全修复见证。但在固定136维线性选择器下，将包络潜力监督换成实际安全见证监督，没有改善“选4条候选能否命中可修复锚点”。

当前证据支持停止这一轮监督策略，而不是继续加时训练、直接进入生成器训练，或把失败归因于底层模型完全不理解运动。已有安全路径、能选中该路径、能用共享生成器修好、能迁移到B，是四个不同问题；本轮只检验前两个。

## 2. 实验设计与标签

- 冻结 F16、native20、原decoder/scorer；无神经模型前向、反向或优化器训练。仅冻结数据上的1022次固定逐案例SLSQP求解，以及6次CPU线性选择器拟合。
- A侧固定哈希选384个 native20 失败且存在包络潜力的窗口，stable/transition/change各128；排除前期64个发现案例涉及的全部56条轨迹，每轨迹每组最多4个窗口。不是全A的随机代表样本。
- 511个潜力锚点，各做shape和pointwise一次；原位置节点4/8/12、半径0.20(t/12)^2、float32 raw到float64路径、K20单锚修正，其余19条原生路径不变。SLSQP零初始化，maxiter150、ftol1e-9，不重启或挑解扫参数。
- P：保存的实际同一条路径同时 ADE≤0.2、FDE≤0.4，满足原位置界、固定19条及完整window五项运动学≤native×1.01，并经生产与独立算术双验证。
- N：Fraction端点必要条件证明超出0.2+0.4+1e-9范围；1e-9仅保守负例证书余量，不是质量或运动学评价epsilon。
- U：其他情况，包括未找到见证、求解失败、仅质量达标。U不是不可行负例，也不假定其随机缺失。
- 两臂固定S1b的136维输入与线性LogisticRegression：Envelope将E当正例，Witness只将P当正例并屏蔽U；共同N相同。共同训练窗口须有至少1P及1N，双方共享该折训练窗口全部20候选的统计量。
- 同一三target-track OOF折；C=1、L2、newton-cholesky、tol=1e-6、maxiter500、单线程。显式轨迹等权、窗口内正负各半，总权重20N；class_weight=None。没有特征、阈值、C或划分搜索。

这比较的是正例集合及未知掩码共同变化的“监督策略”，不是只改变一个标签值的纯因果实验。三OOF折也不是三独立模型seed。

## 3. 安全见证与证据量

| 项目 | 数量 |
|---|---:|
| 固定窗口 | 384 |
| 潜力锚点 / 固定求解 | 511 / 1022 |
| 至少一条已验证安全见证的窗口 | 263 / 384（68.49%） |
| P / N / U候选标签 | 329 / 7027 / 324 |
| 已验证P占原E锚点 | 329 / 511（64.38%） |

68.49%是这批机会筛选样本的见证发现率，不是全人口可修复率、部署覆盖率或可学习性证明。未找到的121个窗口仍不等于无解。单锚安全也不保证同时修正4锚或所有人口pooled p95安全。

三折验证分别有86/83/94个P机会窗口、40/37/38条P轨迹；共同训练177/180/169个窗口。每折≥20个P窗口和10条P轨迹的支持门通过。六次拟合均4次迭代、无收敛warning，独立梯度无穷范数最大2.36e-8，低于1e-6。未通过推进不能解释成求解器没收敛或支持门不足。

## 4. 主要结果：命中可修复锚点，不是真实覆盖率

同一263个已知P机会窗口作为分母；选出的4条中只要有至少一个P即Hit4。它不表示一个共享生成器已实际救回这些窗口。

| 选锚策略 | 命中 | Hit4 |
|---|---:|---:|
| 包络监督 Envelope | 69 / 263 | 26.24% |
| 安全见证监督 Witness | 66 / 263 | 25.10% |
| 固定随机4 | 74 / 263 | 28.14% |
| bottom4 | 15 / 263 | 5.70% |
| 旧S1b（仅描述性参照） | 75 / 263 | 28.52% |

均匀随机选4的解析期望为24.14%；固定随机的一次实际28.14%不代表所有随机实现都如此。旧S1b使用不同训练量/统计量，不能作为本轮匹配监督因果对照。

配对target-track bootstrap：115条轨迹、2000次、三项Bonferroni校正98.333%区间，差值均为Witness减参照，单位百分点。

| 比较 | 差值 | 98.333% CI |
|---|---:|---:|
| Witness − Envelope | −1.14 | [−3.22, +0.79] |
| Witness − 固定随机 | −3.04 | [−12.09, +6.70] |
| Witness − bottom4 | +19.39 | [+10.07, +28.21] |

Witness明显胜过bottom4，但未胜过匹配Envelope或随机。相对Envelope区间上界约+0.79pp，达不到预注册+5pp工程收益；相对随机区间很宽，不能反过来宣称随机已被证明优于Witness。窗口/场景相关、仅三OOF折及重复研究适应性，限制总体外推。

## 5. 运动变化组是关键弱点，不能用stable成功掩盖

| 原组 | 已知P窗口 | Envelope | Witness | 固定随机 | bottom4 |
|---|---:|---:|---:|---:|---:|
| stable | 98 | 44（44.90%） | 42（42.86%） | 29（29.59%） | 1（1.02%） |
| transition | 88 | 12（13.64%） | 12（13.64%） | 21（23.86%） | 9（10.23%） |
| change | 77 | 13（16.88%） | 12（15.58%） | 24（31.17%） | 5（6.49%） |

stable中Witness高于固定随机是必须保留的正面反例，但transition/change没有同样收益。change三折分别Witness6/3/3，Envelope6/3/4，随机7/7/10；三个折均未达到不劣于随机的推进条件。

场景同样不一致：zara的64个P窗口Witness28、随机18；university的194个P窗口Witness37、随机54；hotel只有5个P窗口，Witness1、随机2，不能做可靠场景归因。不能只挑zara覆盖overall或change失败。

## 6. 为什么更严格监督没有带来改善？

以下是保存数据支持的解释线索，不是唯一根因证明。

**实际训练对比小于511个E看起来的差异。** 全部511个E里有182个尚未验证为P，但133个位于没有P的窗口，已按原共同训练规则排除。共同训练池263个窗口中，Envelope正例378、Witness正例329，实际只多49个未知E。该规则保证双方训练输入可比，却缩小了监督差异并引入“已发现见证”条件选择，不能据此否定其他安全监督方法。

**两臂排序高度相似。** 384个窗口有327个选槽集合完全相同（85.16%）；263个P窗口有225个相同（85.55%）。总体Hit4仅差3个窗口。

**当前表示/排序对变化锚点仍弱。** 保存OOF诊断中，Witness在change里的最佳P平均rank11.08、中位rank12，而stable约6.19/5。change的P分数高于N的候选配对比例只有46.09%；总体56.90%。这不是独立新显著性检验或唯一容量证据。P与U的配对比例尤其不能叫真实二分类AUC，因为U不是已知负例。

固定历史后，当前136维线性分数仍对候选路径呈仿射关系；共有P2历史偏置抵消，12个速度交互提供有限历史条件作用。简单筛P对N并屏蔽U，也不直接教会模型把真实P排在所有U之上。可达性/时间形状的非线性匹配，是值得区分的后续假设，而不是本轮已验证的修复。

## 9. 反方检查（academic-research-suite；同助手inline，非外审）

**DA2：是否只是“监督无效”？** 不能这样外推。共同训练实际只差49个正例，133个未知E随无P窗口排除；P是求解发现的安全下界而非完整真实可修复标签。此次仅否定当前固定策略达到预注册收益，不能否定所有安全监督或生成方法。

**DA3：是否可以绕门直接S2？** 不可以。GT逐案例见证不是GT-free共享生成器；Witness仍漏掉197个已知机会，change三折都不及随机。stable/zara正例、模型收敛、明显胜bottom4都不能替代整体及change门。固定4同时修正、B迁移与pooled motion还没有验证。

# R2固定非线性匹配：实验结果与推进决策

日期：2026-10-13，香港时间。**状态：计算与独立保存审核PASS；科学推进门FAIL；本轮分析交付完成。不进入B迁移或S2。**

## 1. 结论

固定64个RBF特征扩展带来了正面但有限的排序信号：在同一263个已经确认存在安全修复见证的窗口中，top4命中从线性控制66个提高到77个，增加11个窗口（+4.18个百分点）。change命中从12/77提高到19/77，最佳P排名中位数从12改善为9。

但这不足以进入下一阶段：RBF相对固定随机74/263仅增加3个窗口（+1.14个百分点），主比较校正置信区间跨0；三个change折仍全部低于固定随机。因此停止这个固定RBF探针，不继续扫带宽/中心数/C，不延长训练，也不绕门开始生成器或scorer训练。

**“排序改善信号”不等于“安全生成成功”。** 本轮没有生成或修正新轨迹，也没有产生新的候选minADE/FDE、部署覆盖率或运动学改善；它只决定原20条候选中选哪4条锚点。[原始结果](RESULT.json)

## 2. 本轮实际设计

采用父目录预注册方案，不修改旧设计快照：[设计](../../EXPERIMENT_DESIGN.md)、[协议](../../protocol.json)。

- 唯一因素：L136原线性特征 vs L136加固定RBF64；含截距可拟合系数137 vs201。容量、核几何及有效正则化同时变化，不能叫等容量对照或纯历史因果实验。
- 固定R1保存的384个A侧机会窗口、原三target-track OOF折、P/N/U=329/7027/324、共同训练条件（至少1P及1N）。训练窗口177/180/169，验证机会窗口86/83/94，机会轨迹40/37/38。
- 原136维：P2观测96、native路径24、最后观测速度和速度变化4、原速度交互12。全部输入来自已观测历史及immutable native预测，不新增GT输入。
- 每折64个中心按训练ID×physical slot的SHA标签 `r2-fixed-rbf64-v1` 固定选取，不看标签/GT/场景/效果；历史块100维、候选交互块36维分别取标准化平方距离均值，RBF=exp[−0.5(dH+dQ)]，带宽固定1。
- 原特征与RBF统计都只使用该折共同训练窗口全部20候选；std<1e−6替换为1。验证数据不拟统计或中心。
- 两臂同Witness监督：P正、N负、U屏蔽。U不是不可行负例，也不假定随机缺失。每轨迹总权重相等，每窗口正负各半，总权重20N；class_weight=None。
- LogisticRegression：C=1、L2、newton-cholesky、tol1e−6、max_iter500、单线程。没有早停或超参搜索。总计6次生产CPU拟合；预检throwaway拟合不算新的科学结果。
- 所有原F16/native20/decoder/scorer及R1标签、路径、失败来源均只读。没有重跑1022次逐案例求解，没有Torch/神经模型前向、反向或生成器训练。B、outer、inner、CAL不参与本实验。

主指标是同一263个已知P机会窗口上的Hit4：选4条中至少一条被已保存安全见证证明为可修复。它不是“选出的生成器实际救回了窗口”。见证标签存在固定求解预算的发现偏差，263/384也不是总体可修复率。

## 5. 拟合与OOF差距

六拟合全部收敛，无warning；线性均4迭代，RBF均5迭代。最大独立梯度∞范数：线性1.77e−8、RBF2.74e−10，均低于原1e−6门。原线性控制三折统计/权重/分数/top4重现R1 EXACT。不是实现没收敛。

训练内目标值每折由0.64391/0.64732/0.64141降为RBF的0.57598/0.58235/0.59256。这只是训练内拟合改进，不能代替验证收益。

## 7. 科学推进门与决策

- 原支持门：三折PASS。
- 四项收益门（各≥5pp、98.75% CI下界>0）：FAIL。
- 每change折不劣于全部四参照：三折FAIL。
- 总筛查门：FAIL。因此B未评估、S2未启动。

停止这个已预注册固定RBF探针，不扫中心数、带宽、C、宽度、标签阈值或划分，不自动增加模型容量/训练时间，也不改scorer。当前结果没有否定所有非线性表示，亦没有证明F16不理解运动或发现唯一根因。

若后续研究另获精确授权，首先应区分“有P与N判别信号、却不足以进入top4”到底来自集合内排序目标还是训练发现标签/迁移偏差；可考虑固定现有表示与标签的短预算排序目标对照，未知U继续屏蔽，样本和门预先锁定。**这只是候选下一问题，不是本轮已验证方案或已启动实验。** 不能以本次A结果调方案后再把同A包装成独立确认。B目前无同口径安全P/N/U，需要另行确认设计；不得直接用旧包络标签替代。

后续任何真正生成路径的试验仍须原同完整candidate ADE≤0.2 AND FDE≤0.4、change ADE/FDE各5%收益、保护组1%、三seed/CI、native支撑与所有五pooled motion每seed每group≤native1.01等门，均不放宽。

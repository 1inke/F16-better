## 3. 跨种子一致性

### Speed Scale

- General minFDE：2/3 个种子改善；逐种子为 -2.20%、+0.47%、-1.08%。
- Challenge minFDE：2/3 个种子改善；逐种子为 -1.37%、-0.06%、+0.18%。
- Challenge Same-path FDE：3/3 个种子改善，但幅度仅 -0.27% 至 -0.64%。
- Challenge minADE：0/3 个种子改善，说明它没有改善整条轨迹的 oracle 精度。

结论：存在一个很弱但较一致的终点/路径一致性信号；它不是 minADE 突破，并且 minFDE 的收益仍小于种子波动。

### Dual Temporal

- General Top-1 ADE 与 Top-1 FDE：3/3 个种子改善，说明它确实改善了普通开发域中的模式排序或主预测。
- General minFDE：2/3 个种子改善，均值 -0.78%。
- Challenge minADE：仅 1/3 改善；Challenge minFDE 也仅 1/3 改善。
- Challenge Top-1 ADE：3/3 个种子变差，均值 +1.22%。

结论：双时间分支学习到的是普通开发分布内的主模式选择能力，并没有转化为高速度、高非线性、较低密度条件下的稳定泛化。

## 4. 轻量化代价

- Speed Scale 不增加参数，训练时间与 Baseline 基本相同。
- Dual Temporal 增加 28,945 个参数，即 **+10.17%**；平均训练时间约增加 **6.8%–7.2%**。
- 以当前不足 1% 且不跨域稳定的 oracle 收益看，Dual Temporal 的成本收益比不合格。

## 5. 最关键发现

Challenge 相对 General 的 Baseline 缺口为：

- minADE：0.180862 → 0.302045，恶化约 **67.0%**；
- minFDE：0.331217 → 0.601339，恶化约 **81.6%**。

这比两种改动带来的 0%–1% 变化大两个数量级。EXP-134 已显示高速度轨迹的 CV 中心偏差很大；本实验进一步说明，仅把速度标量加入状态，或简单增加一个短—长期时间分支，都不足以解决“运动尺度与轨迹形状迁移”问题。

## 6. 决策

1. **不把 Speed Scale 或 Dual Temporal 替换为当前正式模型。**
2. **不进行二者组合实验。** 两个单模块均未通过 minADE/minFDE 的跨种子、跨划分门槛，组合会扩大搜索而缺乏可靠依据。
3. Speed Scale 仅保留为机制线索：速度信息需要影响特征归一化、时间尺度或交互尺度，而不是只作为附加状态输入。
4. Dual Temporal 当前形式停止；其 General Top-1 改善可记录为模式排序线索，但不符合当前优先提升 minADE/minFDE 与域外泛化的目标。

## 7. 下一轮优先方向（仍不改解码器）

1. **运动形状—尺度解耦编码**：以速度尺度归一化位移/速度序列，用独立门控重新注入 log-speed、加速度和曲率，使编码器分别学习“形状”和“物理尺度”。
2. **运动困难样本重加权**：在训练损失或采样中提高高速度、高曲率、低密度样本权重，直接缩小 Challenge 域缺口，而不反复针对固定验证样本调参。
3. **尺度条件稀疏交互**：保持 Top-K 稀疏结构，但让距离/关系偏置按目标速度与预测时间尺度归一化，使高速目标的有效交互范围随运动尺度变化。

优先级建议：先独立验证 1 和 2；通过后再把 3 作为注意力偏置层面的单变量实验。

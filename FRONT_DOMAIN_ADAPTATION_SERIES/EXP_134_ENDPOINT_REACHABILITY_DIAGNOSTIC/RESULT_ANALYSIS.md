# EXP-134：终点可达域诊断结果

## 结论

五折等权下，CV FDE为 `1.1476`，固定K20锚点Oracle FDE为 `0.5490`，学习后minFDE为 `0.4428`。固定锚点相对CV降低约52.2%，学习偏移又相对固定锚点降低约19.3%，说明运动学锚点和上下文学习修正都有效。

候选端点平均两两距离为 `1.9249 m`，小于0.1 m的近重复候选仅 `1.18%`。因此没有证据支持“当前候选集合普遍塌缩”。best-ADE与best-FDE模式一致率为 `66.2%`，存在路径—终点错位，但不是完全失配。

## ETH定位

- 全ETH：CV `2.2819` → 固定锚点 `1.2808` → 学习后 `1.0323`；
- ETH高速组：CV `3.7713` → 固定锚点 `2.4360` → 学习后 `1.9006`；
- ETH低密度组：学习后minFDE仍为 `1.0846`；
- 学习偏移平均幅度由ETH全体 `0.6921 m`上升到高速组 `0.7665 m`。

候选端点跨度在ETH全体为 `1.9409 m`，高速组反而为 `1.9117 m`，没有随运动尺度增加。这说明固定网格提供了多样性，但集合尺度缺少样本级扩张能力。ETH的主要残差来自CV中心在高速/非线性条件下偏离过大，以及固定跨度和有界offset不足以完全补偿。

## 决策

1. 否定“候选塌缩是当前主要瓶颈”的强结论；
2. 支持以后研究样本级整体候选尺度调制，而不是继续无约束增加单锚点自由度；
3. 该诊断仍不能完全分离“前端没有预测出正确offset”和“offset可达域不足”，需要结合非解码实验判断。

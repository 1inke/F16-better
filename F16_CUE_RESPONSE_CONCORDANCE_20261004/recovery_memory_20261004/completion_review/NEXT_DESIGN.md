# 下一步设计建议：曲线可达性与已学习候选的差距

状态：DESIGN_ONLY_NOT_LAUNCHED；非正式第三轮。提出于本次诊断之后，不能称公开预注册或既定收益。

## 可辨识问题

FIT/CAL主要缺口是同一候选粗事件相符但全路径差。只问：在固定原native20、原观测速度推导bound下，现有单脉冲修正族是否能构造至少一条ADE<=.2m且FDE<=.4m的完整候选？若存在可行构造，再量化已学输出到该构造的缺口。不是推断真实意图或产生部署收益。

这不是“表达与学习只能二选一”；观察歧义、约束、优化、损失和泛化可同时存在。

## 固定数据与对照

仅FIT25912/CAL2879，锁原ID与坐标；所有窗口不因GT结果删去。优先分层：clear、specific first-compatible、coarse-response/path-inadequate，并报告全部和无事件反例。DEV不用于构造、挑预算、调阈值或新架构。

三条比较线：
1. 原native20与已学习输出的保存结果（若FIT/CAL没有保存某已学模型输出，先核实授权和恢复路径，不能拿DEV效果替代或新训补洞）。
2. **同原单脉冲函数族**逐窗口、逐native slot的GT辅助参数构造：drift2、vector amplitude2、center/span，保留原允许范围/clip/integration。GT只进入事后拟合目标，不进入任何部署forward；不更新F16或head模型。
3. **同bound的逐步修正superset**作为宽松可达性参照，并给必要几何下界。非新的learnedhead实验、非放宽运动学major标准。

局部拟合到一条达标轨迹是可行证据；多初值未达标不等全局不可达。必要下界只有超阈值时才能作不可达证据；若仅下界通过，不能保证可达。clip-box参照更宽不代表pulse达到它。

## 求解与审核先行，而非盲开实验

先检查现有脉冲生产函数与bound逐项对应、FIT/CAL已有预测覆盖、SciPy/凸求解器可用性。预先固定确定性多初值、优化步数/预算与数值容差；不按CAL收益选择center/span搜索范围或部署参数。精确求解方案和计算规模必须在数据结果产生前锁定。

至少独立重算构造path、同slot质量、每步clip、原endpoint/profile规则、有限K20以及模型/source SHA；记录收敛/未证实而非把local失败归为不可达。不拼两个slot的minADE/FDE。

主输出：native/当前已学/GT构造覆盖、rescued/lost、每窗可行证据等级、原始与GT无关去重有效好簇。逐时误差/事件解释仅辅助。GT辅助可达不能宣称模型理解或性能保证，原全组运动学保护仍不放宽。

## 决策

- 单脉冲大部分可行但当前未学成：不再优先增加曲线自由度，聚焦条件化学习/训练泛化；若需新loss/监督/解冻，停止请人类精确决定。
- pulse构造困难但superset有严格可行证据：提出独立候选specific速度/航向状态参数化对照；仍不能把局部pulse失败当不可达证明。
- 两者都困难或参考数据/求解无法给可辨识证据：中断计划等人类，不能无限扫宽度/LR/epoch或修改质量标准。
- scorer41例保持单独队列，不能用评分解决缺少好路径。

## 资源与工作节点

人类约17GB可用hostRAM约束持久有效。预估输入/输出/临时矩阵、单窗求解内存、FIT全量算术上界；默认串行、最多256行小批，进程预算<=6GiB，系统physical+commit各保留>=6GiB。当前诊断实际private约2GiB不是新优化求解的保证。

下一推进先20–35分钟实现可行性/固定预算/小规模压力及独立算术预检；整诊断暂估15–40分钟，必须根据实际工作量修正，不把设计估计当已启动ETA。合法实际launch才保存新folder/source/runtime/唯一OS worker/PID/start、单次50%TIME与完成节点，并退出会话；不对话轮询。出现实质阻碍停等人类。

本设计不启动新训练或新worker；原study2/3和全部旧结果不变。

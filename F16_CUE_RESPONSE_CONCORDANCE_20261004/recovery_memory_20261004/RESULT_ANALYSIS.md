粗响应包含事件、类型、方向、时刻±2步及强度；这一组每个窗口至少有一条同candidate通过它们，但没有一条完整路径合格。它不是所有候选都正确，也不是证明网络有益使用了线索。±2步=±0.8秒且标签粗糙，可能掩盖很重要的形状/时间误差。

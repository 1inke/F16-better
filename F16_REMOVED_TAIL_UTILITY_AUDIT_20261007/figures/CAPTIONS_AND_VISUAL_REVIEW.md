# Rank–utility figures: captions and visual review

All panels show **native20**, not a trained ranking model. Rank 1 is the highest original frozen native logit, with stable original-slot tie handling. Grey shading marks ranks 17–20, the unchanged removal policy. Each rank contributes one candidate per window; means include all windows, including zero utility. Coverage utility is the fraction of windows in which removing that one candidate destroys same-candidate ADE≤0.2m AND FDE≤0.4m coverage, displayed in percentage points. ADE/FDE utilities are leave-one-out oracle error increases, displayed in millimetres. J utility uses min-slot max(ADE/0.2,FDE/0.4). Exact ties have zero marginal utility.

Outer is primary; inner and original CAL are secondary. Three columns refer to grouping populations, not paired samples. Native outputs are exactly repeated across seeds; only seed42 is plotted after the full audit verified equality. CAL native population is identical across all three columns, so its repeated curves are **not three independent datasets**.

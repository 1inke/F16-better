# EXP-195A 结果分析

## 结论

EXP-195A 已完成 8,000 个训练目标与 2,000 个验证目标的正式实验。当前结果支持 AV2 低成本桥接方案可行，并表明更高时间分辨率的历史轨迹主要改善短时运动建模。

- **AV2 桥接可行：是。** A1 相对 CV baseline 的 selected ADE/FDE 分别降低约 7.9%/9.1%。
- **高分辨率历史有效：初步支持。** A3 相对 A2 的 minADE20/minFDE20 分别降低 2.17%/1.64%，selected ADE/FDE 分别降低 3.47%/3.49%。
- **当前最高精度：A3（20 Hz）。** minADE20=0.1959，minFDE20=0.3249，selected ADE=0.4538，selected FDE=0.9401。
- **当前最佳精度—效率折中：A2（10 Hz）。** 精度接近 A3，而 batch=64 的延迟、吞吐与显存明显优于 A3。
- **暂不切换 Mamba。** A3 相对 A1 的 batch=64 延迟增加约 22.7%，未达到预设的注意力扩展瓶颈触发条件（延迟增加超过 50% 且精度收益小于 1%）。

> 关键限制：A2/A3 均从训练后的 A1 checkpoint 继续训练 4 个 epoch，而 A1 是从 ETH checkpoint 训练 4 个 epoch。因此 A1 与 A2/A3 的差异混入了额外 AV2 训练收益。当前最干净的时间分辨率对比是 A2 与 A3；在做因果结论前，应补充“A1 checkpoint + 2.5 Hz + 再训练 4 epoch”的 continued-A1 对照，并至少运行多随机种子。

Zero-shot 的 selected ADE 比 CV 略差约 1.1%，而 selected FDE 基本持平；这说明未经 AV2 适配时，候选轨迹本身有潜力，但候选选择仍是主要瓶颈。训练后 A1 已在公平的 selected 指标上显著超过 CV，证明低成本桥接有效。

## 时间分辨率收益

A3 相对 A1 的 minADE 在 1.0/2.0/3.0/4.8 秒处分别改善约 14.4%/9.4%/6.5%/4.5%；selected ADE 分别改善约 11.1%/7.8%/6.3%/5.0%。收益随预测时间增长而减弱，符合“高频历史主要帮助速度、加速度和短时转向估计”的预期。

A3 相对 A2 的正式指标改善较稳定：

- minADE20：2.17%
- minFDE20：1.64%
- selected ADE：3.47%
- selected FDE：3.49%

由于 A2 与 A3 使用相同的 A1 起点并各训练 4 个 epoch，这组对比是当前最可信的分辨率证据。

## 正式效率测试

测试协议：CUDA，warmup=200，timed_forwards=1000，forwards_per_measure=20；分别测试 batch=1 和 batch=64。

| 方案 | batch | median latency (ms) | throughput (samples/s) | peak memory | FLOPs |
|---|---:|---:|---:|---:|---:|
| A1 | 1 | 12.184 | 81.49 | 0.92 MB | 53.69 M |
| A2 | 1 | 12.435 | 80.10 | 1.88 MB | 78.86 M |
| A3 | 1 | 12.161 | 81.93 | 5.21 MB | 129.21 M |
| A1 | 64 | 12.636 | 5054.75 | 60.67 MB | 53.69 M |
| A2 | 64 | 12.778 | 4966.90 | 120.89 MB | 78.86 M |
| A3 | 64 | 15.498 | 4086.95 | 277.46 MB | 129.21 M |

batch=1 主要受固定启动开销影响，三个方案延迟接近；batch=64 更能反映分辨率扩展成本。A3 相对 A1 的 batch=64 延迟增加约 22.7%、吞吐下降约 19.1%、峰值显存约为 4.57 倍、FLOPs 约为 2.41 倍。绝对显存仍低于 0.3 GB，因此当前阶段的瓶颈尚不足以支持立即改用 Mamba。

## 数据诊断

- 训练集：8,000 个目标，来自 5,404 个 scenario；验证集：2,000 个目标，来自 1,391 个 scenario。
- 严格筛选后没有缺失样本。
- 验证集约 84.6% 的目标只有 0 或 1 个有效邻居，因此本实验更偏向验证时间建模，而非复杂社会交互建模。
- 邻居截断比例约为训练集 15.1%、验证集 13.4%，后续若研究拥挤交互，需要单独扩大邻居容量并做控制实验。

## 建议的下一步

1. 补做 continued-A1 对照，消除额外训练 epoch 的混杂。
2. 对 A1/A2/A3 至少运行 3 个随机种子，报告均值与标准差。
3. 若 continued-A1 后 A3 仍有稳定收益，再推进长历史实验。
4. 继续保留 A2 作为部署型候选、A3 作为精度上限候选；只有在长历史导致延迟明显恶化时再评估 Mamba。

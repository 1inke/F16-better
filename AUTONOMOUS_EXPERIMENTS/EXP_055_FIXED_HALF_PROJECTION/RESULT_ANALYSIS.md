# EXP-055 结果分析：固定矩阵双段投影

F36 用固定 2×8 矩阵替代 F35 的 `reshape + mean`。加载同一 F35 checkpoint 后，在 64 样本 batch 上：

- 轨迹输出最大绝对差：**0.0**
- mode logits 最大绝对差：**0.0**
- 参数量：二者均为 **284,642**

因此 F36 的所有精度结果严格继承 F35，无需重新训练。

顺序运行的 CUDA 基准曾显示 4%–8% 加速，但交换顺序后排名反转。最终使用 18 轮交替测试抵消 GPU 时钟漂移：F16/F35/F36 在 batch=1 和 batch=64 的端到端均值差异都小于约 1%。可靠结论只有峰值前向显存从 58.44 MiB 降到 54.58 MiB（约 6.6%），以及 attention 核心理论操作减少约 67%。

F36 作为更适合矩阵 kernel 的等价实现保留，但不能宣称显著端到端加速。

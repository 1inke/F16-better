# 自主连续实验总目录

本目录记录持续模型改进实验。每次模型结构发生变化时，建立新的 `EXP_xxx_*` 文件夹，并保存：

- 实验动机与唯一变量；
- 对应代码或代码快照；
- 完整运行命令与配置；
- 原始日志、检查点和指标；
- 中文结果分析与下一轮决策。

共同约束：在单个编码器对照系列内部固定解码器和评分协议，但允许在独立实验系列中比较、替换 Q20 解码器；优先保持轻量化、稀疏交互和运动学先验；目标测试集只用于最终冻结模型评估，不参与中途选择。

长期探索分为三条相互隔离的路线：

1. 轻量时间/状态编码器；
2. 稀疏社会交互与运动学图先验；
3. 多模态解码、轨迹参数化和模式评分（Q20 只是其中一个基线）。

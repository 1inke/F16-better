# EXP-025 时间—社会交叉注意力：阶段分析

## seed=1 结果

| 模型 | 参数量 | Original ADE/FDE | Fused ADE/FDE | minADE20/minFDE20 |
|---|---:|---:|---:|---:|
| F4+K20 | 284,541 | 0.5168 / 0.9039 | 0.4484 / 0.8018 | 0.1579 / 0.2460 |
| F10+K20 | 284,642 | 0.5046 / 0.9328 | 0.4567 / 0.8325 | 0.1617 / 0.2478 |
| F16 时间—社会交叉 | 284,642 | **0.4984 / 0.8786** | **0.4289 / 0.7834** | 0.1634 / 0.2619 |

F16 不增加参数，同时显著改善最终选择指标：相对 F10，Fused ADE 改善约 6.1%，Fused FDE 改善约 5.9%；相对 F4 同种子也分别改善约 4.3% 和 2.3%。Original ADE/FDE 同样优于 F10。唯一代价是 oracle minADE/minFDE 没有改善，说明收益来自更准确地选择和融合已有候选，而不是扩大候选覆盖。

## 机制解释

原流程先把每名行人的 8 帧历史压成一个 agent token，再进行社会注意力。F16 让每个行人的摘要 Query 在原稀疏邻居集合内直接查询邻居的全部历史时刻，因此能够识别“交互发生在哪一帧”，同时复用原 Q/K/V 投影和关系 token。结果支持当前瓶颈是过早时间压缩，而不是模型容量不足。

## 阶段决策

该方案进入多随机种子复验。若复验稳定，它将成为新的主编码候选；仍需关注推理 FLOPs/延迟增加，因为参数不增加不代表计算量完全不变。

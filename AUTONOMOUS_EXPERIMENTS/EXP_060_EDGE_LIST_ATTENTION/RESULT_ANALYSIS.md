# EXP-060 结果分析：边列表稀疏注意力

F41 与 F16 使用相同权重时，在包含 9/6/3 个有效行人的混合 batch 上：

- 预测最大绝对差：8.34e-7；
- 模式 logits 最大绝对差：2.61e-7。

因此它在数值精度范围内保持 F16 的数学语义。

| 指标 | F16 | F41 |
|---|---:|---:|
| 参数量 | 284,642 | 284,642 |
| 训练耗时 | 209.6 s | 209.3 s |
| 第 30 轮 ADE/FDE | 0.4984 / 0.8786 | 0.5962 / 1.0193 |
| 最佳 checkpoint ADE/FDE | 0.4702 / 0.8551 | 0.4879 / 0.8697 |

单种子训练轨迹会因 scatter 求和顺序的微小数值差异而分叉，因此不能把最终精度差解释为数学机制差异。更关键的是，当前约 9 个行人的小张量上，边列表 gather/scatter 没有获得可测训练加速；209.3 秒与稠密 F16 的 209.6 秒等价。

结论：保留为大规模行人数或自定义融合 kernel 的正确性原型，不作为当前 ETH/UCY 主实现。

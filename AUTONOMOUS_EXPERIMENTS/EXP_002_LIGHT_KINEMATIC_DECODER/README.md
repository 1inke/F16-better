# EXP-002：轻量运动学锚点解码器

## 动机

EXP-001 的 F4 编码器显著改善模式选择，但 `minADE20` 比 F0 恶化约 17.8%。本实验不再固定 Q20，保留 F4 编码、稀疏运动学图和训练协议，比较 Q20 与轻量运动学锚点解码器。

## 解码器

- `q20`：原 ModeQueryEndpointPCADecoder；
- `kinematic_k12`：12 个航向坐标锚点 + CV 基线 + 3 阶正弦残差；
- `kinematic_k20`：20 个航向坐标锚点 + CV 基线 + 4 阶正弦残差。

新解码器显式保留常速度先验，锚点覆盖纵向速度变化与左右偏移；正弦残差在首尾自然受控。它不使用 Transformer 解码层，参数量显著低于 Q20。

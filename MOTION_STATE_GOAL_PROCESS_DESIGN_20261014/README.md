# 运动状态—目标—过程一致性：实验设计总览

日期：2026-10-14｜版本：1.0｜状态：**DESIGN ONLY，未实施、未预检、未启动训练**。

本包是对 G1/G2 结果后的新方案，不修改旧预注册、已完成模型、结果或自动任务。文中的门槛是待实施方案的事前决策规则，不代表任何新实验已经通过。当前用户请求是交付设计文档。

## 1. 要解决的大问题

仅根据已有观测，在固定 K20 预算下，生成更多**同一条完整路径同时准确、运动学合格、可跨行人及场景迁移**的候选。

将问题拆成三个不同假设，而不是连续调试同一个曲线模块：

| 阶段 | 可证伪问题 | 唯一主要对照 | 新训练预算 |
|---|---|---|---:|
| M1 | 显式动态历史是否提供 P2 之外的有效信息？ | 同容量末速度支路 vs 真实速度/加速度序列支路 | 2 臂×3 seed＝6 runs |
| M2 | 固定目标是否阻碍完整运动过程学习？ | 同一新动力学解码器下，冻结目标输出头 vs 联合更新目标输出头 | 2 臂×3 seed＝6 runs |
| M3，条件性 | K20 应分配给不同去向，还是同去向的不同过程？ | 20 目标×1 过程 vs 5 目标×4 过程 | 2 臂×3 seed＝6 runs |
| V，条件性 | 收益依赖什么信息，能否迁移？ | 一致的 raw 干预；固定结构在时间/场景隔离中的匹配复核 | 冻结诊断；重训另计 |

首批只考虑 M1 与独立的 M2，不提前实现 M3/V 全矩阵。M1 阴性不取消 M2；M2 可按固定回退规则使用原 G1 表示。每项只有一个预定版本，不扫描宽度、系数、候选数或训练轮数。

## 2. 已有证据与不能越过的结论

依据：[G1 报告](../GENERATION_BRANCH_SCREEN_20261014/G1_goal20_20261014/RESULT_ANALYSIS.md)、[G2 报告](../GENERATION_BRANCH_SCREEN_20261014/G2_frozen_goal_process_20261014/RESULT_ANALYSIS.md)、[G2 保存数据审核](../GENERATION_BRANCH_SCREEN_20261014/G2_frozen_goal_process_20261014/completion_review/REVIEW.json)。

- outer 变化窗口共 253：G1 完整覆盖 77/72/82，G2 为 99/90/106，native 为 110。
- 同终点 G2−G1 平均覆盖 +8.43215pp，校正区间 [2.11573,16.06136]pp。支持中间过程有实际价值，不证明理解意图。
- 预测终点覆盖 147/139/152，仍低于 native 的 161；终点上界门通过不等于目标优于 native。
- G2 的 48 个 seed×split×group 中 46 个至少一项运动学失败；outer 变化组平均加速度高约 20–22%。固定桥不再续训或扫系数。
- G2 FIT 变化覆盖较强，但 outer/CAL 变化覆盖仍低于 native，不能把所有失败归为单一 loss、表征、优化或分布偏移。

**保留“目标与过程需要分别检验”的研究问题，放弃“当前三次桥必然是正确实现”的假设。** 本包没有把旧 G2 的继续门从 FAIL 改成 PASS，也不是自动启动旧 G3。

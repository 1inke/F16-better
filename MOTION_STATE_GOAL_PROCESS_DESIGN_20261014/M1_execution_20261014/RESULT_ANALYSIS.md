# M1 结果分析：显式动态历史没有带来可靠的增量目标支撑

日期：2026-10-14（香港）  
状态：**执行与完整保存审计 PASS；研究门 S1 FAIL；两臂 major FAIL；M1 结束，系列未完成。**

## 1. 结论

在相同P2、相同34,146参数目标网络、相同训练预算和K20候选数下，显式读取真实速度/加速度序列的B臂，**没有可靠优于只读末速度的A臂**。outer变化人口253窗口/68个target tracks中：

- A完整覆盖78/76/70，B为74/70/72；B−A平均−1.0540pp，26-family校正区间[−6.8557,+5.8323]pp。
- A终点覆盖143/148/137，B为141/130/147；B−A平均−1.3175pp，校正区间[−12.4784,+8.6915]pp。
- B变化minFDE三个seed均比A更差；保护组误差限制也未满足。S1五个组成条件全部未通过。
- B完整覆盖相对native110均更低，平均−15.0198pp，校正区间[−26.1734,−5.0680]pp；B−native变化ADE/FDE/J校正区间均为正，当前方案弱于原生支撑的证据比B−A的比较更明确。

**不应把这一结果写成“历史无用”“P2必然丢信息”或“B与A等价”。** 区间仍允许一定改善或损害；这里只能说当前固定GRU输入实现没有取得预定可靠增量。P2可能已经包含相似历史，额外序列也可能更难优化或包含噪声。

按照结果出现前已固定的规则，M2采用三个seed各自的**原G1**为共同父模型，而不是挑M1-B的seed44、改用M1-A或依据CAL选择。M1阴性不取消独立的M2结构问题，不续开旧G2三次桥。

# 注意力计算机制第二轮实验

本系列固定 F10 前端运动编码、运动学稀疏图、K20 轻量解码器、损失函数和训练协议，只比较注意力计算机制。

## 首轮实验

| 实验 | 变体 | 核心变化 |
|---|---|---|
| EXP-057 | F38 | 早期 6 帧均值 + 最近 2 帧原样保留，K/V 时间长度 8→3 |
| EXP-058 | F39 | 早期趋势 + 最大加速度事件 + 末帧，K/V 时间长度 8→3 |
| EXP-059 | F40 | 按运动速度相似度把 8 个历史 token 压缩为 4 个簇 |
| EXP-060 | F41 | 保持 F16 数学形式，只对运动学图的有效边执行注意力 |

首轮统一使用 scene 1、seed 1、30 epochs。通过首轮精度门槛的候选再进入 seed 2/3 和跨场景验证。

最终结果见 `FINAL_REPORT.md`。F38 进入了三种子、五场景和调度复验；默认模型仍为 F16，F35 保持低显存稳定候选。

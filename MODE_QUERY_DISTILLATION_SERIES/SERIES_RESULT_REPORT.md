# 模式查询与轻量蒸馏两条实验链总结

## 最终结论

本轮完成了两条预定实验链的首筛与条件决策：

1. **轻量链：F47 最终协议验证未通过，取消 F16→F47 蒸馏。**
2. **精度链：MQ-1 与 MQ-2 均未通过跨场景 oracle 门槛，取消 MQ-3 的局部 agent×time 扩展。**

停止后续阶段不是运行中断，而是执行预先约定的止损条件，避免为已显示负收益的结构继续扩大计算量。

## 核心对比

| 实验 | 主要变化 | 参数量 | scene 1 minADE/minFDE | scene 3 minADE/minFDE | 决策 |
|---|---|---:|---:|---:|---|
| F16 基线 | 稀疏交互编码 + K20 | 约 284.6K | 0.134141 / 0.211124 | 0.187221 / 0.360196 | 当前参照 |
| F47 | 多尺度时间替换编码器 | 216.8K | 0.133200 / 0.215613 | 0.187669 / 0.364073 | 不蒸馏 |
| MQ-1 | K20 加固定锚点几何条件 | 286.9K | 0.133586 / 0.208909 | 0.189144 / 0.362921 | 不晋级 |
| MQ-2 | 每模式读取 8 个历史 token | 297.5K | 0.132188 / 0.216189 | 0.189085 / 0.365108 | 不晋级、不做 MQ-3 |

## 得到的研究判断

- 当前短板不是“候选完全没有模式身份”。原 K20 已有学习式 mode embedding、固定运动学锚点和有界路径修正；再注入固定几何只能改善部分场景或 Top-1，无法稳定改善 oracle 覆盖。
- 去掉时间平均、让不同模式独立读取历史证据，确实能把 scene 1 的 minADE 推到 0.1322，但代价是终点覆盖变差。这说明现有损失和查询先验不足以让时间证据服务于终点多样性。
- F47 的轻量性成立，但在最终统一协议中存在约 1%–2% 的终点精度损失。没有可靠教师—学生互补证据时，蒸馏并不是优先投入方向。

## 下一步优先级

下一轮不建议继续扩大通用注意力或检索范围。更有针对性的顺序是：

1. **端点条件化但不改候选生成数量**：用速度、航向变化、曲率或可达域参数生成/调制 query，使每个模式首先对应不同的终点假设，再读取时间证据。
2. **训练目标修复候选集合**：在保持解码结构不变的前提下，尝试终点覆盖分配、模式排斥/去重或集合匹配损失，直接解决 MQ-2 暴露的“minADE 好、minFDE 坏”。
3. **有效智能体局部化**：只有上述终点查询有效后，才把检索扩展到经过运动学筛选的少数邻居，并显式跳过 padding，避免 MQ-2 的 77% 时间增长。

这三步仍然保持原有稀疏注意力、轻量目标和运动学先验；重点从“再加一种注意力”转向“让候选查询与终点多样性真正对齐”。

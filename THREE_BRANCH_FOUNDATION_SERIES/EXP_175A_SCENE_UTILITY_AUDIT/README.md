# EXP-175A：SDD 场景信息效用审计

本实验不训练模型，也不改动当前候选生成器。它冻结 EXP-175S0 的
F16 + H3 + Joint-V2（默认 seed 1），用已经离线生成并与视频对齐的
SegFormer-B0 六通道语义图，判断场景信息是否能区分 20 条候选中的好轨迹与坏轨迹。

主要输出：

- oracle-best、原始 Top1、其余候选的场景违反率；
- 候选场景可行性与负轨迹误差之间的 Spearman 相关性；
- 路径、终点、三锚点的可行走性，边界穿越数和最小边界距离；
- validation、test、little、non-little 及 17 个测试视频的独立结果；
- 轨迹到像素/语义图的对齐诊断；
- 是否值得进入 EXP-175B 的预注册判据。

进入 EXP-175B 的建议门槛：17 个测试视频中至少 12 个视频的 oracle
候选违反率低于其余候选，同时验证集关系同向稳定，并满足验证集
macro Spearman >= 0.20 或 oracle 违反率相对下降 >= 20%。
